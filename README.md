# 📊 Madhav Ecommerce Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard built to analyze Madhav Ecommerce sales data. It helps users monitor sales performance, profit, quantity sold, customer behavior, payment modes, and category-wise insights through interactive visualizations.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Track monthly profit trends.
- Identify top-performing states and customers.
- Compare sales by product category.
- Analyze payment mode distribution.
- Provide interactive filtering using slicers.

---

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Excel Dataset

---

## 📈 Dashboard Features
- KPI Cards (Sales, Profit, Quantity, AOV)
- Monthly Profit Analysis
- State-wise Sales Analysis
- Customer-wise Sales Analysis
- Category-wise Quantity Analysis
- Payment Mode Analysis
- Quarter and State Slicers
- Interactive Cross Filtering

---

## 📊 Key Insights
- Uttar Pradesh generated the highest sales.
- COD was the most used payment method.
- Clothing category contributed the highest quantity sold.
- November recorded the highest profit.
- Top customers contributed significantly to total revenue.
